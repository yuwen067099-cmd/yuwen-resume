# 曾語文 Rachel Tseng｜互動履歷

本專案收錄曾語文 Rachel Tseng 的互動式網頁履歷與 A4 列印版履歷。

## 首頁

開啟 `index.html` 後會自動導向最新版的 `yuwen-resume-responsive.html`。

## 履歷版本

- `yuwen-resume-responsive.html`：筆電、平板與列印皆適用的互動履歷
- `yuwen-resume-a4-business.html`：A4 商務版
- `yuwen-resume-a4-editorial.html`：A4 編輯版
- `yuwen-resume-a4-executive.html`：A4 專業商務版
- `yuwen-resume-a4-portfolio.html`：A4 視覺實績版

所有履歷內容均以實際提供的工作經歷、證照及照片為基礎。
